# Dice-roller

A simple Python programme that simulates rolling a six-sided dice.

About

I created this project while learning Python as part of my Software Development T Level.

The programme generates a random number between 1 and 6 and displays the result to the user.

Technologies Used

* Python
* Random module

💻 What I Learned

This project helped me practise:

* Using the random module
* Variables
* User input
* if statements
* while loops
* break
* .lower()

How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open dice_roller.py in a Python editor such as VS Code.
4. Run the programme.
5. Follow the instructions in the terminal.
